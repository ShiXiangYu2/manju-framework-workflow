# S1 · 情绪契约与故事引擎

> 挂载阶段：S1 `/定契约`｜出口：`01-framework-brief.md` §A + G1

## 1. 情绪契约：写一句「不带情节」的话

**定义**：观众每集点开，在等哪口气被顺过来。它贯穿全剧，不随单元更换；换的是矛盾，不是契约。

| 合格写法 | 不合格写法 |
|---|---|
| 「等他被当众认出来」 | 「第 8 集男主在宴会上亮出军衔打脸」——带情节、带集号，这是节拍不是契约 |
| 「等她把被夺走的名字拿回来」 | 「讲一个复仇逆袭的爽剧」——是题材标签，没有可结算的对象 |
| 「等那笔账被当着所有人算清」 | 「观众要看爽点」——没有欠账主体 |

**判据**：把这句念给没看过项目的人，他能说出「谁欠了谁、观众在等什么结果」。说不出就是没定完。

契约要配一个**终止条件**：什么变化一旦发生，这口气就顺完了、旧回路无法继续。终止条件必须可核对（例如「那份名单被公开更正」），不能写「变成最强的人」。

## 2. 流派判定（判错后面全白写）

| | **情绪流** | **剧情流** |
|---|---|---|
| 锚 | 情绪契约 | 信息阶梯 |
| 典型题材 | 身份反转、复仇打脸、甜宠、逆袭 | 悬疑、规则怪谈、推理、生存解谜 |
| 冲突组织 | 契约贯穿，单一矛盾按单元跑（一单元 20–30 集、6 回合闭环） | 观众与主角同步或领先获知，靠信息差逐层剥开 |
| 每集结算 | 「反将一次 + 对手付出可见代价」 | 「一条信息被证实/推翻 + 解释空间改变」 |
| 换挡方式 | 换矛盾不换情绪 | 换问题层级，不换谜底方向 |

**判据只需一问**：观众续看，是因为「想看那口气被顺过来」，还是因为「想知道到底怎么回事」。前者情绪流，后者剧情流。混合型要在简报里写明主次，机检按主型走。

## 3. 创作者契约（先锁不可改，再谈创作）

从 S0 情报卡继承，逐条落进简报 §A：

- **不可改的事实 / 主题 / 角色 / 结局承诺**：每条写清落点集号与可见载体
- **允许探索的空白**、**明确拒绝的方向**（防后续悄悄混入）
- **内容禁区 / 语气与尺度**、**希望观众反复获得的体验**
- **不希望作品变成什么**（负面约束比正面形容词更能拦住跑偏）

改动已接受事实前，先展示语义差异与下游影响，不直接覆盖。

## 4. 故事引擎六问（框架层只答这六问，不扩写世界观百科）

```text
1 压力如何反复启动？      什么会一次次找上门，每次都能逼出新局面
2 主角惯常怎么应对？      这招为什么管用、为什么同时惹出新麻烦
3 对手怎么学习与反制？    对手有自己的目标与筹码，受压后会换招，不是降智配合
4 一轮冲突改变什么状态？  知情者名单 / 权力位置 / 证据 / 可用次数 / 代价到期
5 为什么不能轻易退出？    关系义务、身份、承诺、现实限制或自我认同成本
6 引擎何时终止？          可核对的终点，且每次运行都有「还差多少」的刻度
```

一轮回路写成选择链，不写成「发生了几次冲突」：
```text
触发 → 主角出招 → 对手反制 → 阶段性结果 → 新代价/局面变化 → 下一波危机
```

**可升级状态维度**（只留会影响选择的）：权力/许可、知识/误信/证据、关系/联盟/债务、暴露范围、资源/时间、物理状态、道德代价。每个维度写清「当前起点 → 可能怎么变 → 变化会逼谁作什么选择」。

## 5. 框架推断卡（动笔前的最后一道自查）

改编或已有素材时，先答三问，**框架未定不自动往下写**：

1. 这是**谁**的故事？（承受压力并做抉择的人，不是人气最高的角色）
2. 谁在**动**、谁在**变**？（动的人推动事件，变的人承担弧光，可以是两个人）
3. 观众提前知道什么？（比对手多知道一步，或与对手同步被蒙住，**选定一种**不摇摆）

## 6. 人物：只填四件套 + 不变量

| 字段 | 写什么 |
|---|---|
| 欲望 / 诉求 | 想拿到、守住、查清或摆脱什么 |
| 秘密 | 手里护着什么、怕谁看见 |
| 弧光 | 从哪个自我解释，被什么压力逼到换成另一个 |
| 语言指纹 | 市井刻薄 / 隐忍短句 / 官腔… 每场可辨 |
| 身份不变量（漫剧） | 外貌锚点、性格内核、台词风格 —— **锁死** |
| 状态变量（漫剧） | 情绪、服装、伤势、关系阶段 —— 逐集更新 |

不写成长传记。人物是为契约服务的载体，传记写再厚也救不了前三集没有爽点。

## 7. 对抗功能位与弧光变体（v1.1.0 新增，可选速查）

**补的是什么缺口**：§4 引擎第 3 问要求「对手有自己的目标与筹码、受压会换招」，`04` §3 三缝合一要求「对手换层不换欲」，但两处都只提要求、**没给可选的对手类型池**；§6 的「弧光」字段也只写了「从哪个自我解释换成另一个」，没给候选。本节补这两处，不扩写人物百科。

**红线 1 不变**：每个角色仍然只填四件套 + 身份不变量。下面是**功能位**（对手靠什么让主角难受），不是性格标签，更不是人物小传；选完必须落到「目标 / 筹码 / 受压后的反制」三件事上，否则不算填完。

| 功能位 | 施压机制 | 典型形态（归纳，非清单） | 最适合的单元位置 | 换层怎么升 | 固有反噬 |
|---|---|---|---|---|---|
| 伪装位 | 信任被滥用，认知反转 | 表面可信、背后另有所图；以引导者身份误导 | U1 建欠账 | 从「个人撒谎」升到「有一套说辞在护他」 | 一旦被当众证伪，威信不可回收 |
| 规则位 | 合法地封路，不靠蛮力 | 握解释权 / 程序 / 资格认定 | U2 换矛盾首选 | 从「执行规则」升到「制定并修改规则」 | 规则可被反向引用，最怕被自己的条文反打 |
| 操控位 | 制造认知陷阱，让主角打错目标 | 用信息差、替身、假证据调度主角 | U2 中段 | 从「骗一次」升到「让主角自己骗自己」 | 需要持续投入新信息，最易写成降智 |
| 内耗位 | 不加新反派也能施压 | 同伴阵营里的悲观 / 盲目乐观 / 过度保护 / 一味调停 | 单元换代过渡 | 从「拖后腿」升到「占住主角唯一退路」 | 用多了会显得主角团无能 |
| 镜像位 | 与主角同欲不同法，逼主角解释凭什么 | 被低估者、怀疑论者、受害者、现实主义者 | U3 收束 | 从「旁观看客」升到「有权替主角做选择」 | 容易抢走主角的抉择权 |

**用法**：S1 定引擎时先给对手选 1 个主功能位、1 个备用位；S3 换单元时只换功能位、**不换「他追的那样东西」**（`04` §3 三缝合一第 2 条）。上面最后一列要写进「代价」——没有反噬的功能位很快会变成降智配合。

**弧光变体对照**：同一功能位常有正 / 负 / 极端三态，可当「从哪个自我解释 → 被什么压力 → 换成另一个」的候选，例如：

| 三态组 | 可用作弧光的走向 |
|---|---|
| 纯粹 → 迷失 → 恢复 | 从「相信规则」被逼到「谁都不信」，再落到「有选择地相信」 |
| 奉献 → 过度 → 牺牲 | 从「护人」被逼到「以护之名限制人」，最后付可见代价 |
| 节制 ↔ 放纵、善意 ↔ 恶意、开明 ↔ 独裁、造福 ↔ 操纵 | 同一内核的翻转，适合做对手而非主角 |

**硬要求**：弧光写成 `A 态 → 压力（写明集号或事件） → B 态`，且触发事件能在节拍表 `03-beat-table.tsv` 里找到；只写「从天真变成熟」这类形容词不算填完。

**不采纳的部分（说真话）**：资料自带的完整 45 型清单与例证全部不进本包。那些例证出自《哈利·波特》《指环王》《泰坦尼克号》等电影小说，**没有一条短剧/漫剧案例**，属于通用原型学而非「短剧验证过的爆款规律」；清单本身还有编号错乱。这里只归纳「功能位 + 正负变体」这个方法思想，当**选型灵感**用，不当统计规律用。取用边界见 `references/08` §5。
