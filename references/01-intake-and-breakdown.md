# S0 · 情报接入与拉片拆解

> 挂载阶段：S0 `/框架立项`｜入口：创意 / 原著 / 拉片数据 / 飞书 Base 导出｜出口：`00-intake-card.md` + G0

## 1. 先判入口，别一上来就搭结构

| 入口 | 判据 | 本阶段必做 | 禁止 |
|---|---|---|---|
| **A 原创** | 只有一句创意或情绪目标 | 标「无对标、纯原创」；把创意原话存档 | 编造「近 30 天热榜 Top10」之类的假数据 |
| **B 改编** | 有小说/网文全文 | 记录已读章节范围，检查截断、乱序、缺章；**掌握结局、真正反派、重大反转、前后伏笔**后才准定总纲 | 只读开头几章就宣称通读全剧 |
| **C 对标** | 有爆款拉片样本 | 按 §2 维度结构化，多部共现才提炼机制候选 | 单部特征当规律 |
| **D 续写/补框架** | 已有分集地图或整稿 | 保留原文件，只补缺失阶段，标明断点 | 覆盖已接受的事实 |

改编写清「不可改事实」每条落在第几集、以什么可见载体落地；本轮不落地的显式写延后到 EP 几号。新增人物/对手/立场变化要单独交用户确认，并写清「为什么原著已有的人和事承担不了」。

## 2. 对标拉片：记三层，不记观后感

每项拆成 **直接观察**（几秒、几次、什么画面）/ **解释**（解决观众什么问题）/ **未知**（样本不足或各部矛盾处）。只有多部共现且能说清机制，才写成候选规律。

| 维度 | 要量的东西 |
|---|---|
| 系列与集长 | 总集数、首集与常规集时长；首集是否加长、加长段完成了哪些节点；后续是否近似定长连播 |
| 开场第一拍 | 第一帧与第一句的秒数、说话人、性质；开场是当面受压 / 进行中危机 / 旁白压缩前情 / 旁人议论；身份、底牌首次露面的秒数 |
| 信息载体 | 关键信息靠旁白、画面文字（名条/系统面板）、对白说明，还是物证插入镜交代 |
| 对白密度 | 有声占比、每发声秒字数、最长静默位置、一人一句快来回 vs 长独白、末句后留白 |
| 镜头语法 | 平均/中位镜长、超 4 秒镜头占比、景别分布、对峙站位与权力调度、速度线替代真实动作 |
| 集尾接法 | 末句性质、末帧画面、留白秒数；下一集首句是接着说 / 换场 / 复述上一拍 |
| 画幅与形态 | 9:16 竖屏 vs 16:9 横屏；二维动态漫 / 国漫二次元 / 风格化三维 / Q 版 / 实拍；名条与面板版式是否全剧统一 |

**同形态参考基线**（仅作对照，不当质量门槛）：App 连播式三维国漫风 AI 漫剧，首集常加长到 90–225 秒完成「受压 → 底牌上线 → 首次反击」，常规集约 36–63 秒；常规集平均镜长 2.4–3.1 秒，近景类约占一半，有声占比 0.65–0.84，常速每发声秒约 3.9–5.8 字。注意这与红果标准档 90–120 秒 / 漫剧档 60–90 秒不是一回事，**先定播放面再引用基线**。

## 3. 飞书多维表格字段（拉片结果落库）

镜头级最小字段，够用就别加列：

```text
镜号  时间码  画面描述  台词/旁白  景别  运镜  情绪值  钩子类型  爆款机制解释  可复刻提示词  来源集  来源链接
```

逐镜分析之后才有价值的两列：**倒推分镜意图**（这一镜替观众解决了什么）与**复刻蓝图**（换皮不换机制的做法）。只堆画面描述不写这两列，落到框架阶段就用不上。

工具候选（本包不实现拉片）：`bkingfilm/lapian-notes`（1 秒抽帧 + 情绪曲线，MIT）、`wocha-xiaoli/video-shot-analysis-feishu`（逐镜写入飞书 Base，MIT）、`sharon-laicc/viral-video-decomposer`（镜头级爆款机制，MIT）、`pelpeljakob-creator/viral-video-analyzer`（六阶段流水线，需火山引擎，无明确许可）。链接见 `08`。

## 4. 情报卡必填（G0 判据）

- 项目暂定名、一句原始想法（保留用户原话）
- 入口类型 A/B/C/D；改编类的已读范围与缺口
- 播放面与画幅（红果竖屏 / 抖音竖屏 / 优酷横屏…）；这决定单集时长、字数、镜头语法
- 不可更改的来源事实清单（含落点集号或「延后」）
- 内容禁区、结局承诺（未定写「开放」）、难以承受的制作元素
- 对标样本清单（片名 / 集数 / 形态 / 数据出处）；无则写「无对标、纯原创」
- 目标观众反复获得的回报（情绪 / 信息 / 关系 / 权力，选主项）

## 5. 三个常见坑

1. **把拉片数据直接当框架**：拉片是「别人怎么做到」，框架是「我这口气怎么结算」，中间必须经过 S1 契约与 S3 单元链，不能直接抄集数曲线。
2. **对标仿写只换皮不换壳**：先列《对标原剧外壳禁用词表》，再提炼底层戏剧算式，最后换皮；否则撞车。
3. **形态与播放面脱钩**：横屏漫画分镜搬进竖屏红果，近景占比和名条位置全废。播放面在 S0 定死，后面不返工。
