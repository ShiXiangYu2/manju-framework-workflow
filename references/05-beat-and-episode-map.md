# S4 · 分集节拍与单集契约

> 挂载阶段：S4 `/排节拍`｜出口：`03-beat-table.tsv` + G4

## 1. 单集 = 一次有边界的状态变换

```text
可验证的进入状态
→ 当集压力迫使人物追求目标
→ 选择遭遇反制并产生后果
→ 观众拿到当集承诺的部分回报（结算）
→ 一个具体的新决定 / 危险 / 问题形成下一步压力（新债）
→ 可验证的出去状态
```

**顺序不可颠倒：先结算、再欠新债。** 只留悬念不结算，观众觉得被耍；只结算不欠债，下一集没人点开。

每集同时负两个责任：有自己可识别的当集结果；对系列状态（局部目标 / 关系 / 长线证据 / 策略代价）至少贡献一项。

## 2. 15 秒换挡四拍（标准档单集内部）

| 挡 | 时间 | 任务 | 硬要求 |
|---|---|---|---|
| 1 抓人立事 | 0–15s | 强视觉开场 + 报出具体数字/死线 | 前 3 秒见冲突、危机或反差强动作；前 15 秒用大白话挑明赌注 |
| 2 正面交锋 | 15–45s | 施压加码 + 首轮反制 | 对手有自己的目标与筹码，不降智 |
| 3 亮牌翻转 | 45–85s | 亮物证/底牌，**完成本集结算** | 主角有一次可见反将，对手付出可见代价 |
| 4 余波钩子 | 85–110s | 抛新危机、切断章 | 欠一条具体的账，不是藏半句话 |

严禁同集同场景原地踏步反复争同一件事。每回合反驳必须带新增量（新信息 / 新行动 / 新代价），复读前一回合话术即废稿。

**长档**：一集两拍（回合 A / 回合 B），回合 B 施压与反驳各升一档；≈90 秒处设中段小钩（只抬价不爆点）；每 30 秒一个新增量。
**漫剧档**：单集 60–90 秒，四拍按比例压缩；信息优先靠画面文字与物证插入镜，旁白只做补充（见 §6）。

## 3. 前三集节拍卡（动笔前先锁）

| 集 | 骨架 | 必须完成 |
|---|---|---|
| E1 | 受害 + 立场 | 主角受的具体损失、观众知道在等什么、主角做了第一个不可逆选择 |
| E2 | 证据回放 / 考验递进 | 让观众比对手多知道一步，或同步被蒙住（**选定一种**） |
| E3 | 冲突升级 | 对手换招，第一次小规模结算落地 |

按赛道选节奏型（快打脸 / 慢铺垫 / 双线并进 / 悬念递进）。**第 5 集还在铺垫就晚了**；起势段前 15% 内必须出现至少一次小规模兑现。

## 4. 单集契约七字段（节拍表每行的填写依据）

| 字段 | 只写什么 |
|---|---|
| 进入状态 | 会影响本集行动的事实：位置/持物/伤势、谁知道或误信什么、谁占主动谁欠谁、上集留下的决定与危险 |
| 当前压力与钩子 | 观众能立即理解的未稳定局面（见 §5 六型） |
| 目标与反对力量 | 「人物想让谁/什么在本集结束前发生怎样的变化」；反对力量要有目标、筹码、受压时的反制 |
| 因果升级 | 写成选择链：因为 A → 行动 B → 反制 C → 状态 D 改变 → 新选择 E 产生转折 |
| 局势转折 | 让原计划/理解/关系位置失效：换策、被封路、证据使旧解释失效、代价落地、拒绝最想要的东西 |
| 当集兑现 | 看见真实能力或代价、回收部分旧问题、完成一次关系/权力变化、承诺情绪落地 |
| 出去状态与交接 | 下一集可执行的事实：谁做了什么决定、谁知道了什么、权力/资源怎么变、人在哪拿着什么、哪个危险已启动 |

**分集记录只写本集独有的东西**：可从其他字段推导的单步因果链、跨集共用的人物模型、解释性自证、分类标签，都不占分集字段。

## 5. 钩子六型与集尾

| 型 | 触发 | 常见误用 |
|---|---|---|
| 行动钩子 | 人物已在执行高风险策略 | 与本集无关的奇观 |
| 后果钩子 | 上集选择立即反噬 | 只重复承诺不给结果 |
| 矛盾钩子 | 话语与证据同时出现且不相容 | 故弄玄虚的台词 |
| 关系钩子 | 熟悉关系出现新权力位置 | 无铺垫突然翻脸 |
| 决定钩子 | 必须现在选，拖延也有代价 | 假两难 |
| 信息钩子 | 观众获得能重排现场意义的事实 | 把解释当悬念 |

按本集走向选，**不机械轮换**。断章五式：身份将揭、生死一线、情感爆发中断、证据亮到一半、旧账当场被翻出。集尾三种欠账（真相 / 人物 / 关系）循环用，高潮集叠加。

**集间交接硬规则**：出去状态写成「下一集开场必须接住什么」，不写「悬念：他是谁」这种无法执行的话；相邻集不得无解释冲突；所有进出与铺垫/兑现引用要指向已知记录或标为未决。

## 6. 漫剧档的额外约束

- 旁白/独白是**配额制工具**：不代替对抗、不交代设定、不复述动作、不连排；前 3 秒与断章处禁用；独白只写「具体的账」。
- 信息载体优先级：物证插入镜 > 画面文字（名条/系统面板）> 对白 > 旁白。
- 竖屏近景占比高，对峙靠站位与景别调度；群战、多人同框、复杂特效在 S2 已列制作禁区的，S4 不许排进来。
- 示例动作必须**可拍、有物理结果或物证亮牌**。禁止「眼神微动 / 微微一怔 / 若有所思 / 向前推半寸」这类 AI 出片执行不了的无效微动作。

## 7. 单集情绪曲线（v1.1.0 新增，可选）

**补的是什么缺口**：`04` 的四段波形是**全剧**强度分配，本文件 §2 的 15 秒四拍是**任务轴**（谁在几秒做什么）；两者都不回答「这一集观众的情绪怎么起落、最高点在哪」。框架层原先没有单集情绪刻度，这是真空缺。

**它和四拍是同一条时间轴，不是两套表**：把 §2 的四拍直接当作四个情节点，逐点标作用与强度。

| 情节点 | 时间 | 作用（四选一） | 强度 1–10 |
|---|---|---|---|
| 1 抓人立事 | 0–15s | 蓄力 / 推高 / 砸低 / 转折 | 自填 |
| 2 正面交锋 | 15–45s | 同上 | 自填 |
| 3 亮牌翻转 | 45–85s | 同上 | 自填 |
| 4 余波钩子 | 85–110s | 同上 | 自填 |

**四条口径（写进 `06-emotion-curve.tsv`）**：

1. **情绪走势**三选一：`升→降→升` / `降→升→悬` / `平→炸→钩`。相邻三集别全用同一型，否则和「反转手段轮换」一样会疲劳。
2. **作用四标签**：蓄力（铺垫不兑现）、推高（加压且有可见回报）、砸低（代价落地）、转折（旧解释失效）。**禁止四个点全是推高**——一路推高等于没有曲线，观众会麻。
3. **主波必须是全集最高点**：`主波序号` 指向的情节点，强度 = 四点最大值且 ≥8；该点的作用只能是「推高」或「转折」，不许落在蓄力/砸低位。这与 §2「第 3 拍完成当集结算」对位：主波通常就是亮牌那一拍。
4. **主波后 10 秒内要有转折或砸低**：别让情绪在高点平着收尾；第 4 拍的「余波钩子」正好承担这一步。

**强度分怎么填才不是走过场**：只做**本集四点之间的相对刻度**，不跨集比较、不追求客观。写「9」唯一的含义是「这四点里它最狠，且狠到能撑起这一集的兑现」。机检只查相对最高与 ≥8，不替你判断好不好看。

**自检五条的归属**（别重复造规则）：

| 资料里的自检 | 本包归属 |
|---|---|
| 前 3 秒入戏 / 没有废戏（每个情节点答得出「观众此刻该感觉什么」） | 已在 §2、§6 覆盖，不重复加列 |
| 主波 ≥8 分、主波后 10 秒内转折 | 本包 **F19 / F20**（WARN），落在 06 表 |
| 钩子够痒 | 已在 §5 钩子六型 + §1「先结算再欠新债」覆盖 |

**边界（重要）**：逐秒剧情、逐点的观众感受文案、整张单集情绪大纲表单，属于**正文写作层**，本包不收。框架只留上面四条可核对的刻度；需要逐秒情绪脚本时，把 06 表连同 `05-handoff.md` 一起交给下游 `short-drama-factory` 当单集执行卡。

**钩子三型不采纳**：资料里的「信息差 / 情绪断点 / 选择悬念」是按观众心理分的三类，§5 的钩子六型（行动/后果/矛盾/关系/决定/信息）已覆盖且更可执行，不新增分类，避免一集被贴两套标签。

**文件是可选的**：不建 `06-emotion-curve.tsv` 时，F19/F20 完全不触发，G4 与六个必交文件一切照旧；建了才按 WARN 级提示。这样已交付的旧项目不必回填。

## 8. S4 交付栏（G4 检查项）

`03-beat-table.tsv` 每行 = 一集，列见模板。检查：行数 = 总集数、五个核心字段非空、相邻集出去↔进入承接、四段配比 ±5%、卡点间隔 ≥5 集、每集都有结算与新债。
可选：`06-emotion-curve.tsv` 存在时，行数与集号对齐、四条口径过 F19/F20（WARN）。
