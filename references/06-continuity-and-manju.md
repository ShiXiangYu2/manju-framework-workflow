# S5 · 四账台账与漫剧连载一致性

> 挂载阶段：S5 `/建台账`｜出口：`04-ledger.md` + G5
> **无台账不开写正文。** 框架只存在对话里，连写 30 集后伏笔、道具、人物关系必漂。

## 1. 四张账（最小可用集）

| 账 | 字段 | 更新时机 |
|---|---|---|
| **伏笔账** | `setup_id` / 类型 / 首次出现集 / 初始自然理解 / 承诺回答的问题 / 计划兑现或改义方式 / 拟收集团 / 状态 / 关联角色 | 每集新埋立即登记；推进或回收同步改状态 |
| **人物账** | 稳定 ID / 身份不变量（锁死）/ 状态变量 / 存活与退场 / 关系阶段 / 本集策略变化 / 语言指纹 | 每集更新状态变量；身份不变量只在重大转折且经确认才改 |
| **道具账** | 道具 ID / 状态机（在哪、谁持有、是否损坏）/ 首现集 / 视觉锚点 / 叙事功能 | 每次易手或损坏即更新 |
| **规则账** | 规则 ID / 内容 / 首次生效集 / 可靠性 / 失效条件 / 引用集号 | 新增或引用时更新 |

另加**反转手段轮换台账**：相邻 3 集禁复用同一手段（如「亮物证」「电话叫人」「身份掉马」），防止观众提前猜中打法。

**冷热分层**：热台账只放近 5–10 集仍活跃、会影响下一步的条目，写每集前必读；已结清的移入冷归档，不占上下文。

## 2. 伏笔生命周期（漫剧最容易穿帮的地方）

```text
埋设（首现集 + 初始自然理解）
→ 推进（被提及 / 误导 / 证据升档）
→ 回收（兑现或改义，允许升级禁止降级）
→ 结清（移入冷归档）
```

硬规则：
- **埋设后 ≥2 集才可回收**；当天埋当天收等于没有伏笔。
- 回收内容必须与埋设一致；要升级须在台账里写清升级依据。
- 符号型伏笔（令牌、信物、台词口头禅）另设「当前进化态」与「缺席备注」——**符号缺席也是叙事**。
- 长线伏笔必须有拟收集团；到点未收即在机检里报 WARN。

## 3. 七个记忆文件（漫剧连载，框架阶段先建空表）

| 文件 | 作用 | 更新时机 |
|---|---|---|
| 角色档案 | 人设、关系、台词风格；分身份不变量 / 状态变量 | 每集前读，每集后更新状态 |
| 世界观 | 时代、地理、规则、势力 | 初始化 + 扩展时 |
| 场景布局 | 空间结构、道具锚点、角色位置 | 初始化 + 场景变更时 |
| 剧情摘要 | 已发生关键剧情、伏笔、时间线 | 每集后追加 |
| 伏笔表 | 全剧伏笔生命周期 | 每集即时 |
| 故事圣经 | **唯一事实源总纲**：世界规则 / 角色弧光 / 视觉母题 / 禁止变化 | 初始化 + 每 5 集刷新 |
| 角色关系图 | 关系矩阵 + 事件时间线 | 初始化 + 关系变化集 |

框架阶段只建空表与「已承诺条目」，不填逐集内容；逐集内容由下游写正文时回填。

## 4. 故事圣经（一页纸，30 秒锚定全貌）

必须包含五块：
1. **世界规则摘要**：核心规则 2–3 条、力量/科技上限、社会核心矛盾
2. **角色弧光表**：角色 / 身份不变量（3 词）/ 当前状态 / 弧线终点 / 活跃或退场
3. **视觉母题**：符号 / 类型 / 首现集 / 当前进化态 / 关联角色
4. **禁止变化清单**：世界级 + 角色级负面约束（本包最重要的一致性护栏）
5. **主线脉络**：每条主线一句话 / 当前进度 / 下一节点

## 5. 漫剧特有的三类一致性（实拍短剧没有的）

| 类别 | 要锁的东西 | 穿帮表现 |
|---|---|---|
| **角色形象** | 外貌锚点（脸型/发色/瞳色/服饰标识）、名条样式、声线、口癖 | 同一角色跨集换脸、衣服无因由地变 |
| **画风与版式** | 二维/三维/水墨、光线风格、字幕与名条位置、系统面板版式全剧统一 | 竖屏里突然出现横屏构图、面板跳位 |
| **场景与道具** | 场景空间结构、道具状态机、角色站位基准 | 上一集碎了的杯子下一集完好 |

写作时注入的硬约束（交给下游引擎）：角色锁定、世界观锁定、前情最近 5 集摘要、已死角色不可复活、已揭露伏笔必须有回收或明确延续、时间线不得跳跃、新伏笔即时登记。

## 6. 信息与证据设计表（防「观众比人物多知道却没交代」）

| 事实/问题 ID | 世界中实际事实 | 谁知道 / 误信什么 | 观众何时知道 | 可见证据 | 改变谁的选择 |
|---|---|---|---|---|---|

配合铺垫与兑现义务表（setup_id / 首现位置 / 初始理解 / 承诺问题 / 计划兑现方式 / 状态）。**观众提前知道什么**必须与 S1 流派判定一致：情绪流常让观众领先对手一步，剧情流常让观众与主角同步被蒙住。

## 7. S5 交付栏（G5 检查项）

四账齐全且无空表头；每条伏笔有首现集 / 拟收集团 / 状态且间隔 ≥2 集；身份不变量与状态变量分开列；画风与角色锚点写进禁止变化清单；故事圣经五块齐备；反转轮换矩阵已建。
