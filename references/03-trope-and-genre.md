# S2 · 套路、节拍骨架与赛道画风

> 挂载阶段：S2 `/定套路`｜出口：`01-framework-brief.md` §B + G2

## 1. 先给方向候选，再选套路

方向未定时，给 **2–3 个机制不同**的候选。判据：候选之间必须改变**主角策略 / 对抗来源 / 代价结构 / 冲突持续方式 / 终止条件**中的至少两项，只换职业、朝代、标题不算。

每个候选写七项：戏剧承诺、主角惯常策略、主要对抗机制、退出成本、反复回报、引擎终止条件、主要制作负担。记录**选定/组合、选择理由、明确拒绝的方向、仍待确认的分支**。未选方案不进入既定事实。

> 这条比套路表更重要：套路是「已验证的壳」，方向是「这部戏凭什么值得看」。壳选得再准，机制不成立照样第 8 集崩。

## 2. 已验证的套路与开场（31 部爆款统计，作先验不当铁律）

| 4 大套路 | 占比 | 结算对象 |
|---|---|---|
| 身份反转 | 26% | 被看轻的人被当众认出 |
| 复仇回归 | 19% | 旧账被逐条算清 |
| 甜宠纠葛 | 13% | 关系权力位置翻转 |
| 穿越 / 金手指 | 10% | 底牌兑现并付代价 |

| 3 种开场 | 占比 | 适用 |
|---|---|---|
| 惨剧闪回 | 45% | 需要先立「欠账」的复仇/身份流 |
| 冲突直入 | 39% | 打脸/逆袭流，最省时间 |
| 身份觉醒 | 16% | 金手指/重生流 |

**用法**：从统计里选省力路径，但必须在简报里写一句「为什么这部选它」。占比是历史分布，不是质量排序；无明确许可，只取结论不复制原文。

## 3. 救猫咪节拍表：电影 15 拍 → 短剧压缩

| # | 原版节拍 | 短剧落点 | 框架阶段要回答什么 |
|---|---|---|---|
| 1 | 开场画面 | 前 1–2 秒 | 与终场画面对比的那个画面是什么 |
| 2 | 主题呈现 | 前 5 秒内 | 一句台词/画外音，不讲道理 |
| 3 | 铺垫 | 5–15% | 主角「改变前」的状态（只给可见事实） |
| 4 | 催化剂 | 10–15% | 打破平衡的事件 |
| 5 | 争执 | 15–20% | 犹豫是否接招 |
| 6 | 第二幕衔接 | 20–25% | 不可逆决定，进入新世界 |
| 7 | B 故事 | 穿插 | 副线（感情线），可用闪回/旁白替代 |
| 8 | 娱乐游戏 | 25–50% | **大前提兑现**：观众买票要看的核心场面 |
| 9 | 中点 | 50% | 假胜利或假失败，抬高赌注（对位第一付费墙） |
| 10 | 坏蛋逼近 | 50–70% | 反派加码、团队裂痕 |
| 11 | 一无所有 | 70–75% | 失去伙伴/希望/工具 |
| 12 | 灵魂黑夜 | 75–80% | 最低谷 |
| 13 | 第三幕衔接 | 80–85% | 找到新方法 |
| 14 | 结尾 | 85–95% | 高潮对决，用新方法赢 |
| 15 | 终场画面 | 最后 2–3 秒 | 与开场对照，展示变化 |

**超短 6 拍（30–60 秒）**：钩子(0–3s) → 铺垫(3–10s) → 催化剂(10–15s) → 挣扎(15–35s) → 高潮(35–50s) → 终场+情绪欠条(50–60s)。

**连续剧的情绪欠条三型循环**：第 1 集欠真相、第 2 集欠人物、第 3 集欠关系，高潮集三型叠加。别让连续三集都欠同一种东西。

## 4. 10 类故事型与漫剧适配度（选型速查）

| 型 | 公式 | 漫剧适配 |
|---|---|---|
| 鬼怪屋 | 封闭空间 + 威胁 + 有罪之人 | ★★★★★ 悬疑恐怖首选 |
| 如愿以偿 | 普通人 + 超能力/愿望 + 代价 | ★★★★★ 穿越重生金手指 |
| 麻烦家伙 | 普通人 + 极端突发 + 被迫应对 | ★★★★★ 逆袭打脸 |
| 伙伴之情 | 两个不完整的人 + 互补冲突 | ★★★★★ CP 向甜宠 |
| 愚者成功 | 被低估者 + 强大体制 + 以弱胜强 | ★★★★★ 爽文 |
| 金羊毛 | 上路 + 寻物 + 途中成长 | ★★★★ 公路/冒险/奇幻 |
| 变迁仪式 | 人生困境 + 挣扎 + 蜕变 | ★★★★ 情感治愈 |
| 推理侦探 | 谜团 + 调查 + 真相比表象更黑 | ★★★★ 漫剧推理 |
| 法外之徒 / 疯子当家 / 警界搭档等 | — | 按实际题材取舍，不硬套 |

**硬规则**：愿望/金手指必须有代价，否则故事无张力；主角越普通，代入感越强；真相要挑战观众的道德判断，而不只是「猜出凶手」。

## 5. 赛道与画风（漫剧特有，S2 定死）

- **赛道**：从「男频 12 / 女频 14 / 中性 14」40 赛道图中锚定一条，写清心理诉求、爽点密度与曲线型。只取**一张**题材卡校准压力来源，不把百科塞进简报。
- **播放面与形态**：9:16 竖屏（红果/抖音）或 16:9 横屏；二维动态漫 / 国漫二次元 / 风格化三维 / Q 版 / 水墨 / 实拍，选一种并写理由。
- **节奏档案候选**（写进简报，接受后成配置）：首钩秒数、节拍间隔上限、每集反转次数下限、是否峰值收尾、旁白占比上限、首次大兑现落在第几集。
- **制作负担**：难承受的元素（群战、多角色同框、复杂特效、动物/水/火焰）在此列清，S4 排节拍时不许排超出能力的场面。
